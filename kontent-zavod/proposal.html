Кратко о предложении

Изучил ТЗ №1 внимательно. Проект крупный и технически нетривиальный — это не «настройка нейронки», а полноценный программный комплекс с несколькими точками отказа. Готов взяться. Ниже — честное описание что именно я делаю, почему столько стоит, и как можно оптимизировать бюджет.

Что получаете на выходе

  • Ежедневная автопубликация контента в 4 канала (Telegram, Дзен, Яндекс.Карты, сайт) без вашего участия.
  • Автоматические видео с вашим AI-аватаром и клонированным голосом по триггеру из таблицы.
  • Система продолжает работать даже при сбое одного из сервисов — частичный успех вместо полного падения.
  • Ежедневный отчёт в Telegram в 8:50 — «всё OK» или «есть проблема: [что именно]».
  • Инструкции, Loom-видеогайды и 2 онлайн-созвона — вы сможете обслуживать систему самостоятельно.
  • Все workflow, скрипты и документация — в вашем приватном GitHub репозитории.

Почему именно такая цена

Три вещи в этом проекте технически сложнее, чем выглядят в ТЗ:

  • Claude Code на headless VPS. Anthropic специально защищает сессии от серверного использования. OAuth слетает каждые 24–48 часов. Я реализую Python wrapper с circuit breaker: при слёте сессии система автоматически переключается на Anthropic API (pay-per-use) и уведомляет вас. Публикации не прерываются.
  • HeyGen генерирует асинхронно и нестабильно. Видео может занять от 1 до 15 минут, иногда возвращает failed без объяснения. Я реализую Webhook + поллинг как фоллбек, автоповтор при failed, уведомление с кодом ошибки если второй раз тоже не получилось.
  • Статичный сайт. Вместо опасной резки HTML через регулярки — архитектура JSON + pre-generated HTML файлы. Каждая статья — отдельный .html со всеми мета-тегами (og:image, title, canonical). Яндекс индексирует без проблем. Дизайн сайта не трогается.

Всё это — не переусложнение, а защита от реальных сценариев. Если бы я сделал без этого, система сломалась бы в первый же месяц.

Что мне нужно от вас до старта

  • Письменное подтверждение выбора: ASR субтитры (Вариант Б) или без ASR (Вариант А). Это влияет на этап 3.
  • SFTP-доступ к сайту для аудита структуры — до начала разработки блока «сайт» в этапе 2.
  • Подтверждение: HeyGen кредиты для тестирования (минимум 20 кредитов) — за ваш счёт.
  • Письменное подтверждение: «Понимаю, что сессия Claude Code на VPS будет периодически требовать ручного переподключения по инструкции».
  • API-ключи, доступы и брендматериалы — по списку из ТЗ (предоставляете по мере начала каждого этапа).

Гарантии

  • 30 дней бесплатного исправления багов после сдачи каждого этапа.
  • Все workflow в JSON + скрипты + документация — в вашем репозитории. Система работает без меня.
  • Никаких «закладок»: ключи только в .env, секреты не в коде, .env в .gitignore.
  • После гарантийного периода — опциональный договор поддержки 15 000–25 000 руб/мес.

Изменения API внешних сервисов (HeyGen, Anthropic, Яндекс и др.) после сдачи — оплачиваемые доработки по support-договору. Это стандартное условие для проектов с зависимостью от сторонних API. Прошу зафиксировать письменно.
